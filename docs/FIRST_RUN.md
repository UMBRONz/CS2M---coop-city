# Первый запуск: загружается ли мод вообще

## Сборка

Тулчейн не нужен. Нужны .NET SDK, Node.js и установленная игра (путь находится сам через реестр Steam;
другой путь можно задать переменной `CS2GameDir`).

```powershell
dotnet build CS2M/CS2M.csproj -c Release
```

Мод появится в `%USERPROFILE%\AppData\LocalLow\Colossal Order\Cities Skylines II\Mods\CS2M`.
Другу достаточно скопировать эту папку туда же.

## Проверка 1: игра видит мод

1. Запустить игру. В списке модов (Paradox Mods → Local) должен быть CS2M.
2. В главном меню должна появиться кнопка **Multiplayer**.
3. Если кнопки нет или игра падает, нужны логи из
   `%USERPROFILE%\AppData\LocalLow\Colossal Order\Cities Skylines II\Logs\`:
   `CS2M.log`, `Modding.log`, `Player.log`.

## Проверка 2: хост и подключение (на одном ПК не выйдет, нужен второй)

1. Хост: загрузить город → меню мода → Host game → Start server (порт по умолчанию 4230).
2. Друг: главное меню → Multiplayer → Join game → IP хоста, порт 4230.
   Должны совпадать версия игры, набор DLC и версия мода.
3. Сеть: проще всего через Radmin VPN / ZeroTier / Tailscale (IP хоста берётся из этой программы).
   Без VPN хосту нужно пробросить UDP 4230 на роутере.
4. Друг скачивает город хоста и загружается в него.

## Проверка 3: территории

В чате мода:
- `/land` — у обоих по 9 клеток, у хоста слева от центра, у друга справа;
- `/money` — у обоих по 500 000;
- `/claim X Y` на соседней клетке — деньги списываются, клетка ваша (видно у обоих через `/land`);
- попытка построить на чужой или ничьей земле — превью красное, в чате подсказка.

Пока **не синхронизируется стройка**: что построил один, у другого не появится. Это следующий этап.

## Известные риски первого запуска

- Мод собран без постобработки официального тулчейна. Если игра не грузит мод — поставить тулчейн
  (Options → Modding) и пересобрать: проекты сами переключатся на него.
- Защита стройки (`TerritoryBuildGuardSystem`) написана без проверки в игре — см. docs/TERRITORIES.md.
